Todos os cenários de demonstração

Cada cenário chama um endpoint da API oficial com dados reais. Clique em Executar para ver a resposta, ou em Abrir na calculadora para editar.

Base de cálculo unificada (NF-e / NFC-e)

Calcula de uma vez a base do regime geral (CBS/IBS), do Imposto Seletivo e do Simples Nacional, aplicando a vigência de cada componente no ano.

Consultar tabelas oficiais

Tudo é calculado no seu navegador, com as regras e tabelas oficiais dos três repositórios da Receita Federal (base de regras V0073, de 09/11/2026): calculadora-rtc-regime-regular (conferido com a API oficial v1.7.2 em 1.219 casos), calculadora-rtc-simples-nacional (conferido com a API v1.0.2 em 2.289 casos) e calculadora-rtc-gerador-danfse (o próprio gerador oficial compilado para o navegador, com PDF idêntico ao do serviço). Em todos os casos o resultado foi idêntico ao oficial. Monofasia de combustíveis e outros 16 tratamentos ainda não são calculados nem pela calculadora oficial. Geração de XML, pedágio e funções de NFS-e do regime regular ficam na versão com servidor. Os resultados são simulação de apoio e não substituem a apuração oficial.
